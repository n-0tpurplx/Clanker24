## 🚀 Overview

Welcome to **Clanker24**, my personal testing repository for `clank24` on **ATC 24**. Because the main project is **not available yet**, think of this entire repo as a volatile beta/testing release packed with experimental features. 

It is designed to hook into the 24data streaming engine to test backend logic, telemetry syncing, and automation scripts before anything goes live. 

---

## ✨ Features (Under Active Development)

*   **Experimental Telemetry Hooking:** Testing real-time flight data pulls directly from the 24data WebSocket layer.
*   **Chaos-Driven Automation:** Pre-alpha logic scripts designed to see just how fast we can parse flight strips before Node.js explodes.
*   **Guaranteed Bugs:** Features that work perfectly at 3:00 AM and completely break by noon.
